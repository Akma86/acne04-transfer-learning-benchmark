## Research Overview

Acne Vulgaris is one of the most prevalent inflammatory dermatological conditions globally. Manual acne severity grading by clinicians can suffer from inter-observer variability, subjective human bias, and limited access to specialized dermatologists.

This study systematically compares modern Convolutional Neural Networks (CNNs) against Vision Transformers (ViTs) under transfer learning paradigms to classify facial acne severity into 4 standardized clinical tiers following the **Hayashi Acne Severity Criteria**.

---

## Dataset Overview (ACNE04)

The **ACNE04** dataset is an established public dermatological benchmark designed for acne lesion analysis and severity quantification.

### Clinical Severity Tiers
| Level | Severity Classification | Hayashi Clinical Guideline | Image Count | Distribution |
|:-----:|:-----------------------:|:--------------------------:|:-----------:|:------------:|
| **0** | Normal / Clear          | 0 – 5 Lesions              | 483         | ~35.0%       |
| **1** | Mild                    | 6 – 20 Lesions             | 623         | ~45.2%       |
| **2** | Moderate                | 21 – 50 Lesions            | 175         | ~12.7%       |
| **3** | Severe                  | > 50 Lesions               | 97          | ~7.0%        |
| **Total** |                     |                            | **1,378**   | **100%**     |

### File Convention Note
> **Historical Note on ACNE04 Distribution:**  
> In the official distribution, images are named with a typographical anomaly: `levle0_X.jpg` (misspelling of `level`). Automated preprocessing scripts in `notebooks/01_acne04_dataset_exploration.ipynb` and `src/data/dataset.py` natively parse this convention.

## Model Architectures

The benchmark evaluates four candidate architectures covering lightweight edge models, parameter-efficient CNNs, residual networks, and self-attention transformers:

1. **MobileNetV2** (Inverted residuals & linear bottlenecks) — Lightweight baseline optimized for mobile/tele-dermatology deployment.
2. **EfficientNet-B0** (Compound scaling) — Balances depth, width, and resolution with high parameter efficiency.
3. **ResNet-50** (Deep residual learning) — Industry standard deep CNN baseline.
4. **Vision Transformer (ViT-B/16)** (Multi-head self-attention) — Captures long-range visual context across facial regions.

## 7-Stage Incremental Preprocessing Protocol

To systematically isolate and measure the empirical contribution of each computer vision technique, this study introduces a standardized **7-Stage Incremental Ablation Pipeline**:

| Stage | Preprocessing Component | Operational Method | Clinical Rationale |
|:-----:|:------------------------|:-------------------|:-------------------|
| **Stage 1** | **Raw Baseline** | Resize $224 \times 224$ + ImageNet Normalization | Standardized input tensor dimension required by pretrained backbones. |
| **Stage 2** | **+ Data Augmentation** | Random Horizontal Flip, Mild Rotation ($15^\circ$), Color Jitter | Prevents overfitting and simulates natural pose/angle variations. |
| **Stage 3** | **+ CLAHE** | Contrast Limited Adaptive Histogram Equalization on $L$-channel | Enhances micro-textures of comedones, papules, and pustules without color distortion. |
| **Stage 4** | **+ Color Constancy** | White Balance via Gray World / Shades of Gray algorithm | Normalizes ambient lighting and camera temperature differences. |
| **Stage 5** | **+ Face Cropping** | OpenCV Haar Cascade detection with 15% safety padding | Discards non-facial clutter (clothing, hospital backdrop) while preserving lesion margins. |
| **Stage 6** | **+ Skin Masking** | Epidermal segmentation fusing HSV and YCbCr thresholds | Focuses deep representations strictly on skin surface textures. |
| **Stage 7** | **+ Imbalance Handling**| Cost-Sensitive Class Weights ($w_c = \frac{N}{K \cdot N_c}$) & ROS Sampler | Overcomes the severe 6.5:1 class frequency skew, boosting minority grade sensitivity. |

## Workflow & Getting Started

### Step 1: Visual Preprocessing Inspection
Launch Jupyter Notebook to inspect images and visualize the 7 preprocessing stages side-by-side:
```bash
jupyter notebook notebooks/03_preprocessing_ablation_pipeline.ipynb
```

### Step 2: Running Ablation Experiments
Evaluate each candidate architecture incrementally from **Stage 1 (Raw Baseline)** through **Stage 7 (Full Pipeline)**:

```bash
# === MobileNetV2 Ablation Series ===

python src/train.py --model mobilenet_v2 --stage 2 --epochs 30   # + Augmentation

python src/train.py --model mobilenet_v2 --stage 6 --epochs 30   # + Skin Masking

python src/train.py --model resnet50        --stage 7 --epochs 30
```

## Evaluation Protocol & Metrics

Due to the ordinal nature of acne grades and pronounced class imbalance (Level 1 has 6.4x more images than Level 3), standard Top-1 Accuracy alone is insufficient. The benchmark evaluates:

- **Top-1 Accuracy**: General multi-class classification accuracy.
- **Macro-Averaged F1-Score**: Equal-weighted F1 across all 4 tiers to assess minority class performance (especially Level 3).
- **Mean Absolute Error (MAE)**: Measures distance error across the ordinal severity continuum ($0 < 1 < 2 < 3$).
- **Normalized Confusion Matrix**: Visual diagnostic of adjacent vs. distant misclassifications.

## Version Control & Data Management (.gitkeep)

Because deep learning datasets (`data/raw/`) and model weights (`outputs/checkpoints/`) often exceed hundreds of megabytes or gigabytes, they are excluded from GitHub commits via `.gitignore`.

To ensure the repository maintains its clean folder architecture when cloned by other researchers, empty directories contain a lightweight `.gitkeep` file. This tells Git to track the folder structure without tracking large binary files.
